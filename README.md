Projetos de astronomia, matemática, física e programação desenvolvidos por **Joice Souza Martins Santos** — [Matemática & Contexto](https://matematicacontexto.wordpress.com/).

`Python` · `Streamlit` · `JavaScript` · `OpenCV` · `Educação científica`

## Como explorar

Para baixar o repositório:

```bash
git clone https://github.com/JOICEMARTINS84/clubinho.git
cd clubinho
```

Cada laboratório possui documentação e dependências próprias. Para os experimentos avulsos, descarregue o código, salve-o com extensão `.py` e execute com Python. Consulte [o guia de experimentos](docs/experimentos.md) para as dependências e limitações.

## Aplicações educacionais

Os materiais foram reunidos para apoiar aulas, clubes de ciências e atividades de investigação. As simulações são ferramentas didáticas: escalas, hipóteses e aproximações devem ser consideradas na interpretação.
